# 🎄 chrismas-tree v19

可手势控制的 3D 粒子圣诞树：照片环绕、文字环绕、跟着音乐跳动，手掌一捏就把照片"抓"到眼前。

单文件 `index.html`，零依赖，可离线打开（手势需要 HTTPS 或 localhost）。

## 在线预览

`https://<你的用户名>.github.io/chrismas-tree/`

## 目录结构

```
chrismas-tree/
├── index.html      # 整个页面（粒子树 + 照片 + 文字环 + 手势，全在这一个文件里）
├── music.mp3       # 背景音乐《圣诞》
├── photos/         # 环绕的照片，1.jpg ~ 6.jpg
│   ├── 1.jpg
│   ├── …
│   └── 6.jpg
└── README.md
```

## v19 做了什么

- **真实音乐**：换成 `music.mp3`（你上传的《圣诞》），用 WebAudio 分析低频，树的闪烁、照片的轨道、文字的呼吸都跟着节拍走
- **设置面板**（右上角 ⚙）：落雪 / 照片环绕 / 音乐 三个开关，加「散开」「聚合」「换照片」
- **照片环绕**：6 张拍立得卡片沿轨道绕树旋转，尺寸缩小、随深度透视，正面亮背面暗
- **点照片看原图**：单击任意卡片，弹出原尺寸大图（Esc / 点空白 / 点图片都能关）
- **文字环绕**：`MERRY CHRISTMAS ✦ 圣诞快乐 ✦` 沿树脚弧线循环滚动，随音乐起伏
- **手势**：🖐 张开 → 散开；✊ 握拳 → 聚合；🤏 拇指食指捏合 → 抓取照片（再捏一次放开）；手掌左右移动 → 旋转
- **双控制**：手势和按钮都能用 ——「🤏 抓取」「散开」「聚合」按钮与手势一一对应
- 散开 / 聚合期间旋转不中断，动作互相打断也是平滑过渡，不会跳帧

## 手势怎么用

1. 点右上角 **🖐 手势**，允许摄像头
2. 手离镜头 40～70cm，手掌正对镜头
3. 手势要稳住约 0.2 秒才触发；捏合是"一次捏合 = 一次抓取"，不会连发
4. 左下角小窗能看到摄像头画面和手部骨架

没有摄像头 / 拒绝授权 / 模型被网络挡住时页面不会坏，自动降级成鼠标：拖拽旋转、滚轮缩放、双击散开。

## 换成你自己的照片

**方法一（推荐，所有人都能看到）**
把照片传进仓库 `photos` 文件夹，命名 `1.jpg`、`2.jpg` …（张数随意，最多 9 张），页面自动读。

要改文案或照片列表，改 `index.html` 里的 `CONFIG`：

```js
var CONFIG = {
  title: 'Merry Christmas',
  subtitle: '圣诞快乐 · 愿你所愿皆所得',
  ringText: 'MERRY CHRISTMAS ✦ 圣诞快乐 ✦ ',
  music: 'music.mp3',
  photos: ['photos/1.jpg', 'photos/2.jpg', 'photos/3.jpg',
           'photos/4.jpg', 'photos/5.jpg', 'photos/6.jpg']
};
```

**方法二（本机快速预览）**
设置里点「换照片」选图，或把图片拖到页面上，立刻替换（刷新后恢复，适合先看效果）。

## 更新线上版本

1. 打开 GitHub 仓库，进入 `chrismas-tree` 仓库
2. 用 **Add file → Upload files** 把 `index.html`、`music.mp3`、`photos/` 一起拖进去（同名会覆盖）
3. Commit changes，等 1 分钟左右 Pages 自动重新发布
4. 打开 `https://<用户名>.github.io/chrismas-tree/` 刷新（必要时 Ctrl+F5 强刷缓存）

## 已知边界

- 手势依赖 MediaPipe 的 CDN（jsDelivr / unpkg 双备份），国内网络偶尔慢，失败会降级
- 摄像头只在 HTTPS（GitHub Pages 就是）或 localhost 下可用
- 音乐自动播放受浏览器限制：首次点击页面会自动尝试播放，若被拦，点设置里的「音乐」开关即可
- `photos` 为空时显示占位卡，不影响其它功能
